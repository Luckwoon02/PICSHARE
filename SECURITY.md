# Security Policy

## Supported Versions

The following versions of Pixello are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅ |

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please report it to us privately.

**Please do not open a public issue for security vulnerabilities.**

Instead, please send an email to the project maintainer. We will acknowledge your report within 48 hours and provide a timeline for a fix.

### What should be in the report?
* A detailed description of the vulnerability.
* Steps to reproduce the vulnerability (if possible).
* Any potential impact or risk associated with the vulnerability.
* Any potential fixes or mitigations you recommend.
